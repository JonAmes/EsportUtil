Desktop wallpaper

Pushed to every PC in the venue. PNG, JPEG, BMP, GIF or WEBP · max 8 MB.

Drop an image here
or click to browse
Each PC applies it within one heartbeat (up to ~15 s) and keeps its own baseline — removing the venue wallpaper restores each desktop to what it had before. A downed PC keeps its OUT OF SERVICE marker on top until it returns to service.

Venue app installs

Pick a station, then install any of the six venue apps straight from the vendor's own server — the agent streams the download and this page shows its progress live. Each PC reports the installed version; when the vendor exposes a current-version API (Chrome, Firefox) an outdated install gets a red update button.

Installers come from the vendors directly (Google, Mozilla, Valve, Epic, Blizzard, Riot) over HTTPS — never from a third-party mirror. Steam, Epic, Battle.net and the Riot Client self-update in place, so their status shows what is installed rather than a guess about currency; update re-runs the vendor's latest installer for any app.
